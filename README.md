End-to-end marketing campaign performance analysis using Python, Pandas, and Matplotlib.
# Marketing Performance Analysis

## Project Overview
This project analyzes marketing campaign performance across multiple channels using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Key Metrics
- Profit
- ROI
- CPA

## Key Insights
- Google campaigns outperformed Facebook in ROI and total profit.
- Search_B showed the highest scalability potential.
- CPA analysis revealed optimization opportunities.
